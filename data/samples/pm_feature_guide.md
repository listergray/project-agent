# 项目管理功能介绍 · Project Agent 使用手册

> **文档归类**：产品功能说明 · 项目管理
> **适用对象**：项目经理、立项申请人、审批人、研发与实施
> **系统入口**：Web 门户「项目管理」或若依菜单「项目解析 / 项目管理」（iframe 嵌入）

---

## 1. 产品定位

Project Agent 面向立项预研与过程管理，提供：

1. **立项录入**：人工填表或上传文档自动解析；
2. **审批流**：草稿 → 待审批 → 通过 / 驳回；
3. **知识库联动**：审批通过后同步向量库，支持后续对话检索；
4. **AI 助手**：项目预警、待办、统计类问答（面板内嵌对话）。

业务数据（立项 CRUD / 审批）由 **若依 Java 后台** 提供；**文档解析、RAG、Agent** 由 Python 服务完成，经 HTTP 对接。

## 2. 功能地图

| 功能 | 说明 | 典型用户 |
| --- | --- | --- |
| 全部项目 | 列表筛选：全部 / 草稿 / 待审批 / 已通过 / 已驳回 | 全员 |
| 新建立项 | 选择人工录入或文件上传解析，多步向导 | 申请人 |
| 审批中心 | 待审队列，通过或驳回并填写意见 | 审批人 |

| 知识库问答 | 独立对话页，检索制度与已通过项目资料 | 全员 |

## 3. 新建立项（三步）

### 步骤 1：选择录入方式

- **人工录入**：空白表单，填写项目编号、名称、负责人、预算、周期等。
- **文件上传解析**：支持 Word（.docx）、Excel（.xlsx）、PDF、Markdown；自动抽取字段（含文档内图片场景），再人工确认。

### 步骤 2：填写与确认

核对解析结果，修改不准字段；可补充风险等级、项目类型、起止日期等。确认无误后进入提交。

### 步骤 3：提交结果

- **存草稿**：仅保存，不进入审批。
- **提交审批**：状态变为待审批，出现在审批中心。

---

## 4. 审批中心

1. 审批人打开「审批中心」，查看待审项目详情与附件来源。
2. **通过**：填写意见（可选）；系统将项目置为已通过，并触发 **RAG 同步**（写入向量知识库）。
3. **驳回**：须填写驳回原因；申请人可修改后再次提交。

审批人请假时，按《考勤与休假管理办法》指定代理人接收待办。

---

## 5. AI 助手能做什么

- **项目预警**：询问延期风险、待审积压等（结合当前项目列表与知识库）。
- **我的待办**：查询待我审批 / 待我补充的事项。
- **项目统计**：按状态汇总数量等。
- **制度问答**：结合已导入的公司制度文档作答，并尽量给出依据片段。

流式输出过程中可看到工具调用与生成状态；支持新建对话与历史会话。

---

## 6. 与若依的关系

若依提供登录、菜单与权限；项目管理页通过嵌入门户完成交互。Python API（默认 8080）负责解析与智能问答；请勿将密钥写入前端。

---

## 7. 常见问题

| 问题 | 说明 |
| --- | --- |
| 解析字段不准 | 属正常，须在步骤 2 人工确认后再提交 |
| 通过后知识库搜不到 | 同步需数秒至数十秒，刷新后重试；确认服务可用 |
| 演示环境数据 | 部分资源编码查询为示例数据，以界面提示为准 |
