# 企业资源管理平台 · 资产（ASSET）模块手册 v2.4

> **文档归类**：ASSET 模块 · 操作手册 · 2024-12 版
> **适用对象**：资产管理员、部门资产接口人、新员工入职/离职对接人
> **关联单据编码前缀**：`FS-`（固定资产）、`HR-FIX-`（人力福利类固定资产）

## 1. 模块概览

资产模块管理全公司 **可盘点的实物资产**，覆盖四大类：

| 大类 | 说明 | 典型资产 |
| --- | --- | --- |
| IT 设备 | 研发/办公用电脑、服务器、打印机 | 工作站、笔记本、机架服务器、一体机 |
| 办公家具 | 工位家具、会议家具 | 人体工学椅、升降桌、会议桌 |
| 研发设备 | 仪器、测试机 | 示波器、功率计、FPGA 开发板 |
| 其他 | 高值易耗品 | 投影仪、专业摄像头 |

本系统中每台资产都有唯一 **资产编码**，格式为：`FS-<采购年度>-<4位流水号>`，例如 `FS-2024-0876`。
人力福利类资产（如统一配发的办公椅）使用 `HR-FIX-<4位流水号>` 前缀，例如 `HR-FIX-0044`。

### 1.1 模块集成关系

- 与 **HR 模块**：员工入职时 HR 提交"资产申领单"→ 资产模块分配编码。
- 与 **财务模块**：资产入库生成会计凭证，盘点差异走"待处理财产损益"。
- 与 **库存扣减**：资产出库后 `stock` 自动扣 1，`FS-2024-0876` 工作站库存从 38 → 37。

### 2.1 工作站类资产申请流程

1. **发起**：员工在 OA "资产申领"填写用途（开发岗位默认配 `FS-2024-0876`），经理审批。
2. **分配**：资产管理员用 `query_resource_by_code` 查询库存 ≥1 时发放；扣减库存并更新 `updated_at`。
3. **签收**：员工扫码签收，系统自动推送 **FIN-INV-XXXX** 会计凭证到财务模块。
4. **盘点**：每月 25 日资产盘点单自动生成，差异 >5% 触发"二级复核"流程。

### 2.2 服务器类上架规范

- `FS-2024-1021` 服务器统一由运维组（王建国）在 IDC 上架，U 位编号必须登记。
- 出库前必须执行 48 小时 **Burn-In 压力测试**，不通过走 RMA。
- 上架完成后 24 小时内生成财务入账凭证 `FIN-INV-2024-003`，金额 = `374,400 元`。

## 3. 盘点流程

### 3.1 盘点单导入流程

> **对应 演示场景**：资产盘点单导入 + 模糊匹配 + 库存扣减模块。我用 Trae + Cursor + Claude 组合在 8 天完成全栈 3 接口 + 1 定时任务 + 2 前端页面。

三个核心接口：
1. `POST /asset/inventory/importExcel`：上传 Excel，EasyExcel 批量入库 `t_inventory_import`（加 Redisson 锁防重复）。
2. `POST /asset/inventory/preview`：基于 **Levenshtein 编辑距离** + 同义词词典（"存货=库存=stock"，"编号=编码"）做 Fuzzy Top5，前端弹窗让用户确认"是否是这台资产 FS-2024-0xxx"。
3. `POST /asset/inventory/confirm`：确认后扣库存 `stock = stock - diff`，差异大的走二级审批。

定时任务：**每天 03:00** 跑 `inventory-diff-job`，比对"系统存量 vs 盘点实盘"，生成差异报表导出 Excel（对应 Function Calling 第三个工具 `export_to_excel`）。

### 3.2 异常码

| 码 | 含义 | 处理建议 |
| --- | --- | --- |
| INV-001 | Excel 空行超 5% | 请检查模板是否正确 |
| INV-002 | 编码模糊匹配 Top1 相似度 < 0.6 | 前端提示用户"手工补编码" |
| INV-003 | Redisson 锁已被占用 | 同一张盘点单 5 分钟内只能导一次；避免重复扣款 |
| INV-004 | 库存扣减后 < 0 | 走盘点差异审批流，禁止直接扣 |

## 4. 常见问题 FAQ

**Q：`FS-2024-0876` 工作站可以装 Windows 11 吗？**
A：可以。出厂 Win11 Pro 64 位，如需切换 Ubuntu 22.04 请提交 IT 工单。

**Q：`FS-2023-0344` 打印机卡纸怎么办？**
A：属于"维修中"状态，请联系行政部文印组（内线 8321），或提资产报修单，SLA 2 小时响应。

**Q：人体工学椅 `HR-FIX-0044` 可以申请带回家吗？**
A：混合办公员工可申请"长借"，租期最长 12 个月，到期自动归还提醒。直接问 HR 模块同事林晓雯。
