# 企业资源管理平台 · 人力资源（HR）模块手册 v3.1

> **文档归类**：HR 模块 · 操作手册 · 2024-12 版
> **适用对象**：HRBP、招聘组、部门经理、员工自助
> **关联单据编码前缀**：`HR-EMP-`（员工工号）、`HR-FIX-`（福利类固定资产）

## 1. 模块概览

`HR-EMP-<4位流水号>`，例如：

| 工号 | 姓名 | 部门 | 岗位 | 职级 | 状态 | 上级 | 入职日期 |
| --- | --- | --- | --- | --- | --- | --- | --- |

| HR-EMP-1023 | 林晓雯 | 人力资源部-招聘组 | 资深招聘专员 | P5 | 在职 | 周敏（HRBP总监） | 2020-07-01 |
| HR-EMP-0856 | 赵天宇 | 财务部-报表组 | 报表会计 | P4 | 在职 | 孙丽华（财务总监） | 2022-08-22 |
| HR-EMP-0720 | 郑瑞 | 研发中心-算法组 | 算法工程师（NLP） | P5 | 在职 | 陈昊 | 2023-02-14 |

> 演示时：问"陈昊 工号多少" → fuzzy 工具返回相似度 0.9+ 的 `HR-EMP-1001`。

- **CEO 办** → 1 条直线：研发 / 市场 / 财务 / 人力 / 运营 5 条 BP 线。
- 研发中心分：架构组 / 后端组 / 前端组 / 算法组（Agent、推荐、CV）/ 测试组 / 运维组。
- 陈昊（P6）直属上级刘志强（架构总监）；郑瑞（P5）直接向陈昊汇报。

## 2. 招聘与入职

### 2.1 招聘流程（与 代码助手 Agent 对应）

本公司招聘系统 2024 Q4 基于 **LangGraph + RAG + Function Calling** 做了预研版 Agent。
招聘专员林晓雯的典型使用：

1. 问 Agent："**算法工程师（NLP）在职的有哪些？级别 P5+。**" → fuzzy_match_resource 工具返回郑瑞等。
2. 再问："**郑瑞的上级是谁？**" → query_resource_by_code(HR-EMP-0720) → 返回 manager="陈昊"。
3. 再问："**给我导出 P5+ 所有算法同学的名单做面试比对表。**" → export_to_excel 生成 `recruit_compare_20241225_xxx.csv`。

### 2.2 入职 3-3-3 节奏

- 入职前 3 天：林晓雯用"新员工资产礼包"接口一次申请笔记本 `FS-2024-0902` + 办公椅 `HR-FIX-0044`，资产模块自动扣库存。
- 入职第 1 天：IT 开通账号、研发架构组拉代码权限、HR 做文化培训（陈昊作为架构组面试官也会参与 Meet&Greet）。
- 入职第 3 周：部门 1on1 + 试用期 Checklist。
- 入职第 3 月：转正评审，输出《试用期评估报告》→ 推送给财务赵天宇同步职级调薪。

## 3. 在职异动

### 3.1 晋升规则

| 晋升通道 | 周期 | 评审材料 |
| --- | --- | --- |
| P4 → P5 | 每年 3/9 月两次 | 业务贡献 + 技术沉淀 + 跨团队协作 3 份文档 |
| P5 → P6 | 每年 3/9 月两次 | 架构设计 + 带教记录 + 业务指标提升（陈昊 2023 年 9 月晋升答辩案例） |
| P6 → P7 | 年度评审 | 独立带 5 人以上子团队 + 业务线级 OKR 达成 |

> 陈昊（P6 Agent 方向）2023 年 9 月晋升答辩亮点：主导"知识库 RAG + Agent 预研项目"，
> 把文档检索耗时从人均 30min 降到 2min，ROI 已被运维组验证（可量化数据）。

### 3.2 调岗 / 借调

- 部门内调岗：经理审批 → HRBP 周敏复核 → EHR 次日生效。
- 跨部门借调：需走"双经理签字 + HRBP 签字 + 员工签字"，最长 6 个月。
- **资产归属问题**：借调超过 3 个月时，员工名下 `FS-` 类 IT 设备可保留，但 `HR-FIX-` 家具类仍归属原部门。

## 4. 离职流程

1. **离职申请**：员工 EHR 提交 → 经理审批 → HRBP 复核（林晓雯所在招聘组不处理离职，周敏团队处理）。
2. **资产回收**：系统自动调 `query_resource_by_code(工号)` 查名下资产清单 → 生成资产回收单 → 员工签字。
3. **权限回收**：IT 0.5 工作日内完成 AD / VPN / Git / 服务器权限回收。
4. **财务结算**：财务赵天宇 1 工作日内跑《离职结算单》→ 推 FIN-PAY 单据。
5. **离职证明**：3 工作日内寄出 PDF，纸质版 7 工作日内 EMS。
